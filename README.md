# 🏛️ SYNTAXUS — Bharat Heritage & Tourism Atlas

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Vercel-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://syntaxus-bharat-trails.vercel.app/)

🔗 **Live Production Website:** **[https://syntaxus-bharat-trails.vercel.app/](https://syntaxus-bharat-trails.vercel.app/)**

**SYNTAXUS** is an offline-first, culturally sensitive digital atlas and virtual preservation platform for India's sacred monuments, monasteries, caves, stupas, stepwells, and uncharted heritage landmarks. Built for national hackathons (AICTE PS ID 26202), it bridges sacred monastic governance, interactive 360° VR tourism, regional languages, and hyper-local community economic empowerment.

---

## 🌟 Key Features

### 1. 🥽 Immersive 360° WebGL VR Photosphere Tours
* Seam-free spherical equirectangular panorama viewer powered by **Three.js** and WebGL.
* Interactive navigation with gyroscope device orientation, smooth field-of-view zooming, compass heading tracking, and ceremonial ritual audio chimes.

### 2. 🗺️ Pan-India Interactive Topographical Cartography
* Full GIS map exploration powered by **MapLibre GL** with default **OpenTopoMap (Topological Relief)** layers.
* Filter monuments dynamically across Indian regions (*Northern Frontiers, Eastern Corridors, North-Eastern, Western & Central, Southern Peninsula*) and individual states with custom Dharma Wheel geographic pins.

### 3. 🌐 Real-Time Multi-Language Translation
* Instant dynamic translation across **11 Indian languages**:
  * 🇬🇧 English | 🇮🇳 हिन्दी (Hindi) | 🇮🇳 বাংলা (Bengali) | 🇮🇳 தமிழ் (Tamil) | 🇮🇳 తెలుగు (Telugu) | 🇮🇳 मराठी (Marathi) | 🇮🇳 ગુજરાતી (Gujarati) | 🇮🇳 ಕನ್ನಡ (Kannada) | 🇮🇳 മലയാളം (Malayalam) | 🇮🇳 ਪੰਜਾਬੀ (Punjabi) | 🇮🇳 ଓଡ଼ିଆ (Odia)
* Clean UI integration with zero intrusive tooltips or banner pop-ups.

### 4. 📜 Oral Archives, Audio Guides & Digital Soundscapes
* Curated audio histories and folklore narrated with built-in Web Audio API narration synthesis and spatial ceremonial soundscapes.
* Cultural sensitivity badges (*"Approved by Sacred Custodian"*, *"ASI Protected"*).

### 5. 🛡️ ASI & Sacred Monastic Curator Governance Portal
* Role-based access control (RBAC) with secure JWT sessions for authorized archaeologists and heritage guardians.
* Live operational status management (*Open, Restricted, Chanting in Session, Photography Protocols*).
* Complete immutable audit logging (`audit_logs`) persisted in **Supabase PostgreSQL**.

### 6. 🏨 Yatra Niwas Local Hospitality & Artisan Engine (AICTE PS ID 26202)
* Community economic empowerment hub connecting pilgrims with verified local homestays, verified guides, eco-cabs, and regional handicraft artisans.

### 7. 📦 Offline Culture Cache (PWA)
* Progressive Web App service worker architecture allowing travellers to download and browse offline packs for remote Himalayan valleys and heritage corridors without internet connectivity.

## 🚀 Getting Started Locally

### Prerequisites
* [Node.js](https://nodejs.org/) (v18.17.0 or higher)
* [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ayushseal/Syntaxus-BharatTrails.git
   cd Syntaxus-BharatTrails
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory:
   ```env
   DATABASE_URL=postgresql://postgres.zfciycigpgkeovgwlpuf:Ayushseal%4008@aws-0-ap-southeast-2.pooler.supabase.com:6543/postgres
   JWT_SECRET=syntaxus_sacred_jwt_curator_secret_2026
   ```

4. **Run the local development server:**
   ```bash
   npm run dev
   ```

5. **Open in your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)
